01 / PARTNER POLICY

400여 개 제휴사 정책을 공통 속성과 확인 순서로 표준화

Problem

골프장마다 예약·취소·위약 기준의 위치와 표현, 상세 수준이 달라 같은 유형의 문의도 확인 방식이 달랐습니다.

Action

400여 개 제휴사 정보를 전수 확인해 공통 속성을 만들고, 불명확한 내용은 제휴사에 직접 확인했습니다. 정책 변경 시 내부 문서와 FAQ에도 같은 기준으로 반영했습니다.

Result

제휴사와 관계없이 같은 순서로 정보를 찾고 판단할 수 있는 구조가 생겼습니다.

Learning

파트너 운영은 개별 내용을 외우는 것보다 조건·예외·변경 이력을 한 구조로 관리하는 편이 안정적이었습니다.

02 / SETTLEMENT

Learning

Problem
