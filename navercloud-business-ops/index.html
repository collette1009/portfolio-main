SELECTED CASES

한 건을 잘 처리한 사례보다, 같은 문제가 덜 생기도록 구조를 바꾼 사례를 골랐습니다.

01 / PARTNER POLICY & COST RECOVERY배상 회수 14.7×

물류 사고 접수 기준을 다시 정의해 고객 부담과 비용 누수를 함께 줄였습니다.

모든 사고에 같은 증빙과 실물 회수를 요구하면서 접수가 중단되는 문제를, 사고 확인에 필요한 증빙과 불필요한 고객 절차로 분리했습니다.

PROBLEM

사진 3종, 재포장, 실물 보관·회수 요건 때문에 식품 누수·유리 파손처럼 보관이 어려운 사고는 고객이 절차를 포기하면 배상 접수도 중단됐습니다.

ACTION

파트너 사업팀과 실물 회수 생략·증빙 간소화 방향을 도출하고, 내품 사진이 없는 경우처럼 추가 합의가 필요한 기준은 후속 논의로 분리했습니다.

RESULT

비교 월 기준 배상 회수액이 약 50.7만 원에서 744.9만 원으로 확대됐습니다.

NAVER Cloud 연결 · 파트너 운영 조건 재설계 → 예외 기준 정리 → 비용 회수와 운영 효율을 함께 개선
02 / COST EFFICIENCY월 고정비 -66.7%

운영 방식이 바뀌자 고정비도 실제 사용량에 맞춰 다시 설계했습니다.

게시판 중심 운영으로 전화 수요가 줄었지만 기존 6회선 비용이 그대로 유지되고 있었습니다.

ACTION

실제 동시통화 필요량을 기준으로 운영 가능 범위를 산정하고 업체와 축소 조건을 협의했습니다.

RESULT

6회선 → 2회선, 월 528,000원 → 176,000원으로 조정했습니다.

03 / PROCESS & AUTOMATION1,928건 · 7→1

대량 예외를 고객 영향과 기한으로 나누고, 정형 입력만 자동화했습니다.

물류 전환기 재배송 1,151건과 취소 777건이 동시에 쌓인 상황에서 같은 순서로 처리하면 고객 약속과 재고 리스크가 커졌습니다.

ACTION

재배송을 우선 처리하고 관리자 화면의 반복 입력만 Chrome Extension으로 자동화했습니다.

RESULT

반복 등록 동선을 7단계에서 1단계로 줄이고, 잔여 업무량을 기준으로 지원 인력을 3명에서 2명으로 재산정했습니다.

04 / OPERATIONS MONITORING09:00 DAILY

자금집행 목록을 ‘원본을 찾는 업무’에서 ‘우선 확인 대상을 보는 업무’로 바꿨습니다.

당일·필수·일반·누적 미집행·보류 건이 한 목록에 섞여 있어 매번 사람이 원본을 다시 읽어야 했습니다.

ACTION

지급 상태·중요도·납기·운영 영향 기준으로 자동 분류하고, 법정 납부기한이나 서비스 중단 가능성이 있는 항목은 별도로 표시했습니다.

RESULT

매일 오전 당일 우선 확인 대상을 바로 볼 수 있는 요약 구조를 만들었습니다.
