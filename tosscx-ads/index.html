CASE 04 / PRODUCT OPERATIONS · 5→0건

CASE 05 / AUTOMATION · 1,928건 · 7→1 · 3→2명

대량 예외 1,928건을 우선순위로 나누고, 반복 입력을 자동화한 뒤 필요한 인력까지 다시 계산했습니다.

Problem

물류 전환 직후 재배송 1,151건과 취소 777건이 동시에 발생해 고객 약속과 처리량을 함께 관리해야 했습니다.

Action

고객 영향·기한을 기준으로 재배송을 우선 처리했습니다. 이 건들은 모두 물류센터 귀책으로 기준이 정해져 있어 귀책·금액을 포함한 반복 입력값을 Chrome Extension으로 자동화했고, 처리 후 정상 반영됐는지만 마지막에 확인했습니다.

Result

총 1,928건을 유형별로 운영하고 반복 동선을 7→1단계로 줄인 뒤 지원 인력을 3명에서 2명으로 재산정했습니다.

Learning

자동화 범위를 넓혀도 마지막 결과 확인 절차를 두면 오류 가능성을 관리하면서 처리 속도를 높일 수 있었습니다.

핵심 · 고객 영향과 기한으로 대량 예외를 우선순위화하고 귀책·금액을 포함한 반복 입력을 자동화해 7→1단계, 지원 인력 3→2명 재산정
