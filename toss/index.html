01 / VOC → PRODUCT

배송 제약 동일 문의 5건 → 당일 제품 개선 → 추가 인입 0건

Problem

운영 첫날 배송 가능일이 다른 상품을 함께 담았을 때 주문이 되지 않는 동일 문의가 5건 누적됐습니다. 고객 화면에서는 원인 상품과 제한 사유가 보이지 않아 품절이나 시스템 오류로 오인하고 있었습니다.

Action

실제 상품 조합과 재고·배송 조건을 확인해 정책 오류가 아니라 가시성 문제로 정의했습니다. 장바구니에서 원인 상품과 배송 제약을 바로 볼 수 있도록 노출 문구와 조건을 정리해 개발팀에 제안했고 당일 반영됐습니다.

Result

반영 후 동일 문의는 0건이 되었고, 이후 유사 배송 제한 상품에도 같은 안내 구조를 확대했습니다.

Learning

상담을 늘리는 것보다 고객이 실패 이유를 행동 시점에서 이해하게 만드는 것이 고객 경험과 운영 비용을 동시에 줄였습니다.

02 / VOC ANALYSIS

프로모션 VOC 173건 → 142건(82.1%) ‘문구 미인지’

Problem

1+1 혜택이 적용되지 않았다는 문의가 반복됐지만, 고객이 실제로 어느 조건에서 오인하는지 근거가 없었습니다.

Action

VOC 173건을 전수 분류하고 원인 유형·고객 행동 시점을 함께 확인했습니다. 단순 문의량이 아니라 고객이 조건을 놓친 지점을 보려 했습니다.

Result

142건(82.1%)이 ‘문구 미인지’로 확인됐고, 초회 예외 처리와 재인입 시 정책 안내·종결 기준을 분리했습니다.

Learning

상담 데이터를 제품팀에 전달할 때는 ‘불만이 많다’가 아니라 어디에서 어떤 조건을 놓쳤는지까지 정제해야 개선 판단이 가능했습니다.

173건 · 문구 미인지 142건(82.1%) · 정책 기준 혼동 12건 · 홀수 수량 알림 부재 19건
03 / CRM

고객 의도를 자유 텍스트에서 선택값으로 바꿔 후속 판단을 단순화

Problem

고객의 환불·교환 의도가 자유 텍스트에 섞여 후속 담당자가 다시 읽고 확인해야 했고, 같은 문의에서도 해석 차이가 생길 수 있었습니다.

Action

1:1 문의 단계에서 ‘원하는 해결방법’을 선택값으로 받고 해당 값이 CRM의 솔루션 필드까지 이어지도록 유관부서와 구조를 정리했습니다.

Result

후속 담당자가 고객 의도를 바로 확인할 수 있게 되어 재확인 왕복과 해석 차이를 줄일 수 있는 구조가 만들어졌습니다.

Learning

상담 시스템 개선은 화면을 예쁘게 만드는 것보다 다음 담당자가 판단할 때 필요한 정보를 구조화하는 데서 시작됐습니다.

Problem

3PL 전환 초기 재배송 1,151건과 취소 777건이 동시에 발생했고 일괄 재배송 기능이 없어 같은 입력을 반복해야 했습니다.

Action

고객 약속일과 재고 리스크가 큰 재배송을 먼저 처리하도록 분리하고, 정형 입력 구간만 Chrome Extension으로 자동화했습니다. 귀책·금액·최종 제출처럼 책임이 필요한 항목은 사람이 검토하도록 남겼습니다.

Result

재배송 처리를 우선 완료하면서 반복 입력 동선을 7단계→1단계로 줄였고, 이후 일상적인 미출·반품 업무에도 재사용했습니다.

Learning

운영 자동화는 많이 자동화하는 것이 아니라, 판단과 책임이 필요한 구간과 기계가 반복할 구간을 분리하는 것이 핵심이었습니다.

05 / CUSTOMER CENTER

조직 공백에서 SOP·QA·온보딩으로 고객센터 운영 연속성을 유지

Problem

회생 국면에서 기존 팀 인력이 이탈하고 타 부서 지원 인력이 순차 투입돼, 충분한 인수인계 없이 고객센터 기능을 유지해야 했습니다.

Action

CS가 처리할 범위와 타 부서 판단이 필요한 범위를 나누고, SOP·에스컬레이션·금지 표현·책임 주체를 문서화했습니다. 즉시 답변이 어려운 건은 중간안내 후 상태를 유지하고, 지원 인력의 답변과 처리 방향을 검수했습니다.

Result

누적 8명의 지원 인력이 같은 기준으로 업무를 이어갈 수 있었고, 새로운 예외가 생길 때마다 실제 사례를 기준 문서에 다시 반영했습니다.

Learning

고객센터 운영 품질은 개인 숙련도보다 처리 기준·상태 가시성·검수 루프가 얼마나 안정적으로 유지되는지가 더 중요했습니다.
